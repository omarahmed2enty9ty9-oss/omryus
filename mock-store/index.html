Mock Store — local test fixtures

Demo mode (links below) runs the real content script with a simulated service worker — no install needed. It exercises the genuine offer matching, expiry and insertion logic, but tells you nothing about the manifest, permissions or popup.
To test those, load dist/ as an unpacked extension and open the same pages without ?demo.

  • Static cart — plain form, present on load
  • Controlled input — value is wiped unless proper events fire
  • Late cart — coupon field appears after 1.5s
  • Shadow DOM cart — field inside a web component
  • No coupon box — should fall back to "copy it yourself"
  • No discount available — donation-funded code; must not be described as a discount
  • Products page — supported store, wrong page: no card

Dismiss closes the card for that page view only — reload, or open another cart page, and it comes back. That is deliberate: the offer should appear whenever there is a code available at checkout.
