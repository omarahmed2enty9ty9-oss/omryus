How it works

Four steps, and you control the third.

Most of what Omryus does is decide when to stay quiet.

You shop as normal

Omryus only runs on the handful of stores we actually have a code for. Everywhere else it isn't loaded at all — not idle, not watching. Absent.

We show what we've got

A small card appears on the basket page, once. It tells you what the code is worth and when we last checked that it works. Dismiss it and it goes.

You click Apply

Nothing is inserted, and nothing is tracked, before this. That's not a setting you have to find — it's the only way the extension is built to work.

The code goes in the box

The store decides whether it's valid, not us. If we can't find the discount box, we show you the code so you can paste it in yourself.

Codes that save you nothing

We'd rather give it away than pretend.

Some partner codes carry no discount at all — they only track the sale. The industry habit is to slip those in anyway and call it a deal.

We don't. When a code won't lower your price, Omryus says so in the first line, and offers it as a donation instead: add it if you want to, and the whole commission goes to charity. When there isn't a discount, we keep none of it.

Commission reaches us first and we forward it, so this is a promise about our conduct rather than something the shop does automatically — which is exactly why we publish every penny we send.

Privacy

There's no server to send anything to.

Omryus has no accounts, no analytics service and no backend. Nothing about the pages you visit leaves your browser, because there is nowhere for it to go.

What it can see

  • The address of basket pages on the few stores we have a code for
  • Whether a discount box exists on that page

What it never touches

  • Your card, bank or billing details
  • Passwords — it refuses to write into password or payment fields
  • Anything you type into a form
  • Your basket, order history or browsing history

The extension asks for one permission — local storage — plus access to the specific stores we support. Those are listed in the manifest and nowhere else. Read the full policy.

Supported stores

None yet, and we won't pretend otherwise.

Omryus is in development and has no partner agreements. The codes in the extension today are clearly-labelled test data. Real stores will be listed here, by name, once real partnerships exist — and not a moment before.
Questions

The awkward ones first.

How do you make money?

Where a partner programme allows it, we earn a commission when you use a discount code we provided. It costs you nothing extra, and that commission is how Omryus stays free. Codes that carry no discount are the exception: we keep nothing on those, and the whole commission goes to charity. We'll name the charity once the agreement is signed.

Will you overwrite someone else's referral?

No. Omryus inserts a code into the box you can see and does nothing else — no redirects, no rewritten links, no tracking cookies. If a creator or a friend referred you to a shop, that attribution is untouched, because we never go near it.

Do you find every discount?

No, and we won't claim to. We show you the codes we have for the stores we've partnered with. Shopping around is still on you.

Does the code definitely work?

The store decides that, not us. Each offer shows the date we last checked it, so you can see for yourself how fresh it is.

Can I turn it off?

Dismiss any card and it closes. Uninstall and every trace goes with it — there's nothing stored anywhere but your own browser.
