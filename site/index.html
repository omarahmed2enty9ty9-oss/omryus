Find discounts while you shop.

A free Chrome extension that helps you apply available partner discounts at checkout. When we have a code for a store you're on, Omryus offers it. You decide whether to use it.

Add to Chrome — coming soon Not yet on the Chrome Web Store.

How it works

  1. You shop as normal. Omryus only runs on the handful of stores we have a code for.
  2. We show what we have. A small card appears on the cart page. You can dismiss it.
  3. You click Apply. Nothing happens until you do.
  4. The code goes in the box. The store decides whether it's valid — we don't.

If we can't find the discount box, we show you the code so you can paste it in yourself.

Supported stores

Omryus is in development and has no partner agreements yet. The codes in the extension today are clearly-labelled mock data used for testing. Real offers will be listed here once real partnerships exist.

What Omryus can see

  • The address of pages on the stores we have an offer for — and no others.
  • Whether a discount box exists on that page.

What it never touches

  • Your card details, bank details or passwords.
  • Anything you type into a form.
  • Your basket, your order history or your browsing history.

Omryus has no server and no account. Nothing about the pages you visit leaves your browser. The extension requests one permission — local storage — plus access to the specific stores we support.

Full privacy policy

Affiliate disclosure

Omryus is free. Where a partner programme allows it, using a code we provided supports us, at no extra cost to you. That only ever happens after you click Apply discount.

We never overwrite a referral or affiliate attribution that already belongs to somebody else, and we never add an affiliate code when there's no discount for you — a code that earns us money but saves you nothing is one we decline, not one we show you with a disclaimer.

We don't claim to find every discount, or the best price. We show you the codes we have.
